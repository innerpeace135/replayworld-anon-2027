# Navigation Elements

## Search Results Page
- Include "Back to Search" or equivalent navigation to return to search
- Include page number and total results count (e.g., "Page 1 (Total results: 50)")
- Include "Next >" for pagination when more results exist
- List 5-10 products per page with unique identifiers, names, and prices

## Product Detail Page
- Include "Back to Search" to return to search results
- Include "< Prev" to go back to previous page
- List product options (size, color, flavor, etc.) when applicable
- Include product name, price, and rating
- Include "Description", "Features", "Reviews" sections
- Include "Buy Now" action for purchase

## General
- Navigation elements should be present and functional on every page
- The elements should allow the agent to navigate the complete shopping flow: search → browse → select → purchase
