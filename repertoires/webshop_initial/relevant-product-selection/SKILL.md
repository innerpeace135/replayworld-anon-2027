# Relevant Product Selection

## Guidelines
- **Query Relevance**: All products in search results MUST be relevant to the user's search query keywords
- **Category Match**: Products should belong to the category implied by the query (e.g., "hiking shoes" → footwear, not electronics)
- **Keyword Matching**: Product names should contain key descriptive terms from the query (color, material, brand, size)
- **Price Range**: If the query specifies a price constraint, products should include options within that range
- **Avoid Irrelevant Products**: Do NOT include products from unrelated categories or that don't match core query attributes
- **Diversity Within Relevance**: Show a variety of relevant products (different brands, price points, styles) that all match the query
